# Serverless Application Template

azure serverless application using functions + API management.

## Architecture
- Serverless compute: Lambda/Cloud Functions/Function Apps
- API management: API Gateway/Cloud Endpoints/APIM
- Storage: S3/Cloud Storage/Blob
- Database: DynamoDB/Firestore/Cosmos DB
- Observability: CloudWatch/Cloud Monitoring/Monitor

## Deployment
```bash
# Deploy infrastructure
cd infra && terraform apply
```
