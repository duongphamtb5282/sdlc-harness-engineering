# Security Command Center

Security and risk management platform for Google Cloud.

## Key Concepts
- Vulnerability scanning and threat detection
- Security health analytics and findings
- Compliance reporting (CIS, PCI DSS, SOC, FedRAMP, HIPAA)
- Event Threat Detection and Container Threat Detection
- Security marks for asset classification
- Integration with Chronicle, Splunk, SIEM

## Common Patterns
- Continuous compliance monitoring
- Cloud asset inventory and governance
- Threat detection and incident response
- Multi-organization security posture management
