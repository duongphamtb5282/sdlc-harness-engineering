# Cloud Source Repositories

Private Git repositories on Google Cloud.

## Key Concepts
- Private Git repositories hosted on GCP
- Connected repositories (GitHub, Bitbucket mirroring)
- IAM integration for access control
- Cloud Build and Cloud Pub/Sub integration
- Automatic code search across repositories

## Common Patterns
- Integrated CI/CD with Cloud Build triggers
- Mirrored GitHub repos for compliance
- Audit logging with Cloud Audit Logs
- Code search across repositories
