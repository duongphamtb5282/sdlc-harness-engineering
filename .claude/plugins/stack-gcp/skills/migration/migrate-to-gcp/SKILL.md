# Migrate to GCP

Server migration to Google Cloud.

## Key Concepts
- Migrate for Compute Engine (formerly Velostrata)
- OS and application discovery
- Migration waves and test groups
- Streaming migration with minimal downtime
- Cutover and rollback planning
- Post-migration optimization

## Common Patterns
- Lift-and-shift VM migration from on-prem or AWS/Azure
- OS licensing and bring-your-own-license (BYOL)
- Database migration alongside compute
- GKE modernization after compute migration
