# Cloud Profiler

Continuous CPU and heap profiling for Google Cloud.

## Key Concepts
- Low-overhead production profiling
- CPU, heap, contention, and thread profiling
- Always-on profiling with no manual triggers
- Multi-language: Java, Python, Go, Node.js, Ruby
- Integration with Cloud Monitoring
- Flame graph visualization and comparison

## Common Patterns
- Identify CPU hotspots in production
- Memory leak detection and analysis
- Performance regression comparison across deployments
- Cost optimization through performance improvement
