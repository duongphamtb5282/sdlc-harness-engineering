# Cloud Storage

Object storage on Google Cloud — unified, scalable, durable.

## Key Concepts
- Storage classes: Standard, Nearline, Coldline, Archive
- Bucket configuration: uniform vs fine-grained ACL
- Object versioning, retention policies, hold
- Signed URLs, HMAC keys for access
- Object lifecycle management
- Transfer Service for migration

## Common Patterns
- Static website hosting
- Data lake for BigQuery / Dataflow
- Backup and archive lifecycle
- CDN origin with Cloud CDN
