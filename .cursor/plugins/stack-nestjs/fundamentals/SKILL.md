# NestJS Fundamentals

Core NestJS concepts and architecture.

## Key Concepts
- Modules: @Module decorator, feature modules, shared modules, global modules
- Controllers: request handling, route parameters, status codes
- Providers: services, repositories, factories, custom providers
- Dependency Injection: constructor injection, custom tokens, scopes
- Pipes: validation, transformation, built-in pipes
- Guards: authentication, authorization, role-based access
- Interceptors: request/response transformation, logging, caching
- Exception filters: catch and format errors consistently

## Architecture
- Module-based organization by domain/feature
- Provider abstraction for testability
- Global pipes, guards, interceptors in AppModule
