# BigQuery

Serverless data warehouse on Google Cloud — petabyte-scale analytics.

## Key Concepts
- Serverless, auto-scaling query engine
- Partitioning and clustering for performance
- Materialized views, BI Engine, Omni
- BigQuery ML for in-database ML
- Reservations and slot management
- Authorized views and row-level security

## Common Patterns
- Real-time analytics with Streaming inserts
- Data lakehouse architecture
- ML model training with BigQuery ML
- Geospatial analysis with GEO functions
- Multi-cloud analytics with Omni
