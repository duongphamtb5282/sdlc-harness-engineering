# Dataflow

Serverless stream and batch data processing on Google Cloud.

## Key Concepts
- Apache Beam SDK (Java, Python, Go)
- Streaming vs batch execution
- Windowing, triggers, watermarks
- Autoscaling and horizontal parallelism
- Dataflow Prime for cost optimization
- FlexRS for batch cost savings

## Common Patterns
- Real-time data ingestion and transformation
- ETL/ELT pipelines with BigQuery and Cloud Storage
- Event-driven streaming with Pub/Sub + Dataflow
- CDC processing with change streams
