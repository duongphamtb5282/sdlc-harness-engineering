# Swift & iOS

Native iOS development with Swift and SwiftUI.

## Key Concepts
- SwiftUI layout: VStack, HStack, ZStack, LazyVStack
- UIKit for complex custom UI
- State: @State, @Binding, @ObservedObject, @EnvironmentObject
- Core Data / SwiftData for persistence
- Combine and async/await for reactive programming
- App Store Connect and TestFlight distribution

## Common Patterns
- SwiftUI + Combine MVVM architecture
- UIKit + SwiftUI interop for gradual adoption
- Core Data with CloudKit sync
- Fastlane for CI/CD automation
