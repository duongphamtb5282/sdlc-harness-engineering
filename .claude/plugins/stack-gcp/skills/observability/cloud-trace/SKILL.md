# Cloud Trace

Distributed tracing on Google Cloud.

## Key Concepts
- End-to-end latency tracking across services
- Trace sampling for cost management
- Automatic trace collection from Google Cloud services
- Trace analysis with Waterfall View and Trace List
- Integration with OpenTelemetry
- Service mesh tracing with GKE and Istio

## Common Patterns
- Application performance debugging
- Microservices latency analysis
- End-to-end transaction tracing
- Integration with Cloud Monitoring dashboards
