# Cloud IAM

Identity and Access Management on Google Cloud.

## Key Concepts
- IAM roles: basic, predefined, custom
- Service accounts and workload identity
- IAM Conditions for attribute-based access
- Organization policies and constraints
- Policy Analyzer and Recommender
- Privileged Access Manager (PAM)

## Common Patterns
- Least privilege with custom roles
- Workload Identity Federation for external workloads
- Cross-project service account impersonation
- Organization-level policy enforcement
