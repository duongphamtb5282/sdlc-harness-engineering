# Data Fusion

Cloud-native data integration platform on Google Cloud.

## Key Concepts
- Visual data pipeline designer (Wrangler)
- Cloud-native, fully managed
- 150+ pre-built connectors and transforms
- Pipeline Studio for visual development
- Metadata management and data lineage
- REST API for pipeline orchestration

## Common Patterns
- No-code ETL/ELT data integration
- Data migration from on-prem to Cloud Storage/BigQuery
- Real-time data replication
- Self-service analytics data preparation
