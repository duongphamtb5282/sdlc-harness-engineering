# Cloud Logging

Centralized log management on Google Cloud.

## Key Concepts
- Structured and unstructured log ingestion
- Log buckets: regional, log views, index configurations
- Log routers for routing logs to destinations
- Log-based metrics for metric extraction
- Log Analytics with SQL queries
- Error reporting for application errors

## Common Patterns
- Centralized logging with log sinks to BigQuery, Cloud Storage, Pub/Sub
- Log-based alerting with Cloud Monitoring
- Audit logs for compliance and security
- Structured logging from applications and GKE
