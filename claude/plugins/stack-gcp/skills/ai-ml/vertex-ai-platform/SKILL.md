# Vertex AI Platform

Unified AI/ML platform on Google Cloud — from data preparation to model deployment.

## Key Concepts
- Vertex AI Pipelines (Kubeflow-based)
- Vertex AI Training (custom containers, distributed training)
- Vertex AI Prediction (online/endpoint + batch)
- Vertex AI Model Registry and Model Garden
- Vertex AI Feature Store
- Vertex AI Experiments and Metadata

## Common Patterns
- MLOps pipeline: data → train → evaluate → deploy
- Distributed training with GPUs/TPUs
- Model monitoring for drift detection
- AutoML for tabular/image/text data
