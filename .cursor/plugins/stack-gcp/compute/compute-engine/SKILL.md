# Compute Engine

Google Cloud VMs — virtual machines, instance groups, sole-tenant nodes, GPUs.

## Key Concepts
- Machine types: general-purpose, memory-optimized, compute-optimized, accelerator-optimized
- Instance templates and managed instance groups (MIGs)
- Sole-tenant nodes for isolation
- Preemptible / Spot VMs for cost savings
- Confidential VMs for memory encryption

## Common Patterns
- Auto-scaling MIGs with load balancer
- GPU workloads for ML training
- Batch processing with preemptible instances
- Hybrid connectivity with VPN / Interconnect
