# Kotlin & Android

Native Android development with Kotlin and Jetpack Compose.

## Key Concepts
- Jetpack Compose: composable functions, modifiers, layout
- ViewModel + StateFlow for UI state
- Navigation Compose for screen routing
- Room database for local persistence
- WorkManager for background tasks
- Hilt/Koin for dependency injection

## Common Patterns
- MVVM with Clean Architecture
- Compose + Material 3 design system
- Firebase for auth, analytics, push notifications
- Gradle version catalog for dependency management
