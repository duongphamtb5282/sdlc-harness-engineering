# Mobile CI/CD

CI/CD automation for mobile applications.

## Key Concepts
- Fastlane: build, test, deploy automation for iOS and Android
- EAS Build: Expo managed builds in the cloud
- Codemagic: CI/CD for Flutter apps
- TestFlight: beta testing and distribution
- Google Play Console: managed publishing
- Firebase Test Lab: automated device testing

## Common Patterns
- Automated build and upload to TestFlight/Play Store
- E2E testing on device farms
- Code signing management with Fastlane match
- Release notes generation from git history
