# Dataproc

Managed Spark and Hadoop service on Google Cloud.

## Key Concepts
- Managed Spark/Hadoop clusters
- Optional components: Hive, Pig, HBase, Presto, Zookeeper
- Autoscaling with graceful decommissioning
- Workflow templates for job orchestration
- Cloud Storage connector instead of HDFS
- Dataproc Serverless for batch Spark

## Common Patterns
- ETL pipelines with Spark on ephemeral clusters
- Data science notebooks with Jupyter on Dataproc
- Migrating on-prem Spark/Hadoop to GCP
- Machine learning feature engineering at scale
