# Cloud Monitoring

Observability platform for Google Cloud and AWS.

## Key Concepts
- Metrics, logs, traces, and dashboards
- Cloud Monitoring agents and Ops Agent
- Alerting policies and notification channels
- Uptime checks and Synthetic Monitoring
- Service monitoring with SLOs and error budgets
- Cloud Monitoring Query Language (MQL)

## Common Patterns
- Infrastructure monitoring with dashboards
- Application performance monitoring
- SLO-based alerting and error budget burn rate
- Multi-cloud observability (GCP + AWS)
