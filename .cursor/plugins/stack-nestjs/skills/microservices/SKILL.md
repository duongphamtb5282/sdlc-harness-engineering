# NestJS Microservices

Microservice architecture with NestJS.

## Key Concepts
- Transport layer: TCP, Redis, RabbitMQ, Kafka, NATS, gRPC
- @nestjs/microservices: client-server pattern
- Hybrid applications: HTTP + microservice
- Shared interfaces via common lib
- Message patterns and event-based communication
- Saga patterns for distributed transactions

## Common Patterns
- TCP transport for internal microservice communication
- Kafka for event-driven architecture
- API Gateway pattern with GraphQL federation
- CQRS with @nestjs/cqrs
