# Cloud Spanner

Globally distributed, strongly consistent relational database service.

## Key Concepts
- Global distribution with strong consistency
- Horizontal scaling with automatic sharding
- GoogleSQL / PostgreSQL dialects
- Interleaved tables for parent-child relationships
- Secondary indexes, commit timestamps
- Cloud Spanner Change Streams

## Common Patterns
- Global multi-region applications
- Financial services requiring strong consistency
- High-scale inventory / catalog systems
- Gaming leaderboards and state storage
