# Container Microservice Template

aws container-based microservice.

## Architecture
- Orchestration: ECS/AKS/GKE
- Registry: ECR/ACR/Artifact Registry
- CI/CD: CodePipeline/Azure DevOps/Cloud Build
- Service mesh: App Mesh/Istio/Service Mesh
- Observability: X-Ray/Application Insights/Cloud Trace

## Deployment
```bash
# Build and push image
docker build -t app .
```
