# Phase 3: Report

## Objectives
- Produce structured findings report
- Categorize by severity and type
- Provide actionable remediation suggestions

## Report Format
```
  Critical   N    Issue description with file:line
  High       N    Issue description with file:line
  Medium     N    Issue description
  Low        N    Issue description
  ─────────────────────
  Total      N    deduplicated by file:line
```

## Outputs
- `docs/reviews/{change-id}-review-report.md`
- Summary for PR comment or ticket update
