# NestJS GraphQL

GraphQL API development with NestJS.

## Key Concepts
- Code-first approach with @nestjs/graphql + @nestjs/apollo
- Object types, inputs, args, enums with decorators
- Queries, mutations, subscriptions
- Resolvers: query, mutation, field, subscription
- Dataloader for N+1 prevention
- Federation for microservice GraphQL

## Common Patterns
- Code-first schema with auto-generated SDL
- Pagination with Relay-style connections
- File uploads with GraphQL multipart
- Real-time subscriptions with WebSocket
