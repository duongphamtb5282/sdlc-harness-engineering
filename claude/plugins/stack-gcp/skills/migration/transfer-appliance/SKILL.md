# Transfer Appliance

Physical data transfer appliance for Google Cloud.

## Key Concepts
- Offline data transfer for large datasets (100TB+)
- Appliance models: TA100 (100TB), TA300 (300TB)
- Encrypted data with AES-256
- Shipping and tracking via Google logistics
- Data verification and checksum validation
- Direct ingestion to Cloud Storage

## Common Patterns
- Initial data seeding for cloud migration
- Cold data transfer (tapes, archives)
- Large media asset migration
- Regulatory data transfer with offline requirements
