# App Engine

Fully managed serverless application platform on Google Cloud.

## Key Concepts
- Standard and Flexible environments
- Automatic scaling to zero
- Traffic splitting for gradual rollout
- Custom domains and SSL certificates
- Cron tasks and task queues
- App Engine for Firebase integration

## Common Patterns
- Web applications and REST APIs
- Migrating from PaaS to Cloud Run
- Admin dashboards with App Engine Standard
- Task queue-based background processing
