# Flutter

Cross-platform UI development with Flutter and Dart.

## Key Concepts
- Widget tree: StatefulWidget, StatelessWidget, InheritedWidget
- State management: Riverpod, Bloc, Provider, GetX
- Navigation: GoRouter, Navigator 2.0
- Platform channels for native integration
- Firebase integration (Auth, Firestore, Cloud Messaging)
- Flutter web and desktop support

## Common Patterns
- Material Design 3 / Cupertino adaptive UI
- BLoC pattern for scalable state management
- Firebase backend for mobile apps
- Patrol for integration testing
