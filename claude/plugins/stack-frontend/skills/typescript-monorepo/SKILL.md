# TypeScript Monorepo

Managing multi-package TypeScript repositories.

## Key Concepts
- **Turborepo**: high-performance monorepo orchestration, caching, parallel tasks
- **Nx**: extensible monorepo with code generation and dependency graph
- **pnpm workspaces**: fast, disk-efficient package management
- **npm/yarn workspaces**: built-in workspace support
- **Changesets**: versioning and changelog generation

## Common Patterns
- Shared TypeScript config with project references
- Package dependency graph visualization with Nx
- CI pipeline with Turborepo remote caching
- Automated package publishing with Changesets
