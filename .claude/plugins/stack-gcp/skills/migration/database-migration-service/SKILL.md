# Database Migration Service

Database migration to Google Cloud with minimal downtime.

## Key Concepts
- Homogeneous migrations: MySQL, PostgreSQL, SQL Server
- Continuous migration with change data capture (CDC)
- One-time and continuous migration jobs
- Schema conversion for heterogeneous migrations
- Connectivity via VPC peering, VPN, Interconnect
- Pre-migration assessment and validation

## Common Patterns
- MySQL to Cloud SQL migration with CDC
- PostgreSQL to Cloud SQL or AlloyDB migration
- SQL Server to Cloud SQL migration
- Database modernization with schema conversion
