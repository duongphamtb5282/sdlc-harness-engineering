# Workflows

Serverless workflow orchestration on Google Cloud.

## Key Concepts
- YAML-based workflow definition
- Step execution with branching, subworkflows, parallel steps
- Wait states and scheduled execution
- Integration: HTTP, Cloud Functions, Cloud Run, BigQuery, Pub/Sub
- Error handling and retry configuration
- Execution history and logging

## Common Patterns
- API orchestration across multiple services
- Business process automation (order processing, approvals)
- Scheduled data pipelines with Cloud Scheduler
- Error handling with conditional retry and compensation
