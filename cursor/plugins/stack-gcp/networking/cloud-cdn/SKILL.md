# Cloud CDN

Content Delivery Network on Google Cloud.

## Key Concepts
- Low-latency global content delivery using Google's edge network
- Cache modes: static, forced, dynamic
- Cache keys: protocol, host, query string, headers, cookies
- Signed URLs and signed cookies for access control
- Integration with Cloud Load Balancing

## Common Patterns
- Static asset caching (images, CSS, JS)
- Global website acceleration
- Video streaming with cache fill
- API response caching with custom cache keys
