# Phase 1: Scan

## Objectives
- Identify changed files and scope of review
- Determine review depth (full vs targeted)
- Load relevant context (tickets, specs, ADRs)

## Activities
- Run `git diff` against base branch
- Filter files by type (source, test, config, docs)
- Read linked stories or tickets for context

## Outputs
- Review scope document
- File list with risk assessment (low/medium/high)
