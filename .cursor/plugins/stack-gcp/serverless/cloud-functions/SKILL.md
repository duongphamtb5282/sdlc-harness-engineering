# Cloud Functions

Event-driven serverless functions on Google Cloud.

## Key Concepts
- 1st gen vs 2nd gen (Cloud Run-based)
- Event triggers: Cloud Storage, Pub/Sub, Firestore, HTTP
- Function frameworks for Node.js, Python, Go, Java, .NET, Ruby, PHP
- Min/max instances for concurrency control
- VPC access with Serverless VPC Connector
- Secrets integration with Secret Manager

## Common Patterns
- Event-driven data processing pipeline
- Webhook handler for third-party integrations
- Scheduled tasks with Cloud Scheduler + Pub/Sub
- Lightweight API endpoints (2nd gen)
