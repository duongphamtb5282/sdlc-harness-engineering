# React Native

Cross-platform mobile development with React Native.

## Key Concepts
- Component-based architecture (React paradigm)
- Navigation: React Navigation, Expo Router
- State management: Redux Toolkit, Zustand, Jotai, TanStack Query
- Native modules and Turbo Modules
- Expo managed and bare workflows
- Over-the-air updates with EAS Update

## Common Patterns
- Cross-platform app with shared business logic
- Native module bridge for platform-specific features
- Expo EAS Build for CI/CD
- Detox E2E testing and Jest unit testing
