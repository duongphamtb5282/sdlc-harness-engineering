# Pub/Sub

Asynchronous messaging service for event-driven systems.

## Key Concepts
- Topics, subscriptions, and messages
- Push vs pull delivery
- Exactly-once delivery and ordering keys
- Dead-letter topics for failed messages
- Snapshots and seeks for replay
- BigQuery / Cloud Storage / Dataflow subscriptions

## Common Patterns
- Event-driven microservices decoupling
- Ingesting streaming data for analytics
- Fan-out event distribution
- Cross-project/region message replication
- Change data capture (CDC) with Debezium
