# TypeScript Tooling

Modern TypeScript development tools and configuration.

## Key Concepts
- **tsconfig**: strict mode, paths, project references, composite projects
- **tsup**: fast TypeScript bundler with esbuild
- **Bun**: all-in-one JS runtime, bundler, test runner, package manager
- **Biome**: fast linter and formatter (replaces ESLint + Prettier)
- **tsx**: TypeScript execution for Node.js
- **typia**: superfast runtime validator with compiler API

## Common Patterns
- Project references for monorepo type checking
- tsup for library bundling (ESM + CJS dual output)
- Biome for consistent code formatting across projects
- Strict mode with exactOptionalPropertyTypes
