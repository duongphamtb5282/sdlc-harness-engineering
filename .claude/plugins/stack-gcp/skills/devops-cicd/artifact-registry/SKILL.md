# Artifact Registry

Container image and package repository on Google Cloud.

## Key Concepts
- Multi-format: Docker, Maven, npm, Python, Go, APT, YUM
- Regional and multi-regional repositories
- Vulnerability scanning with Container Analysis
- IAM integration for access control
- Remote repositories for external proxy
- Virtual repositories for aggregated view

## Common Patterns
- Container image storage for GKE and Cloud Run
- Maven/npm proxy for CI/CD pipelines
- Immutable tags for deployment traceability
- Vulnerability scanning in deployment pipeline
