# TypeScript Testing

Testing strategies and tools for TypeScript projects.

## Key Concepts
- **Vitest**: fast Vite-native test runner with Jest-compatible API
- **Jest**: established test runner with ts-jest or @swc/jest
- **Playwright**: E2E testing with TypeScript support
- **MSW**: API mocking that works in Node, browser, and test environments
- **Testing Library**: React Testing Library, Vue Testing Library
- **Cypress**: Component testing and E2E testing

## Common Patterns
- Vitest for unit + integration tests (fast, ESM-native)
- Playwright for cross-browser E2E tests
- MSW for API mock servers in test mode
- Coverage thresholds with c8/istanbul
