# Vertex AI Agent Builder

Build and deploy AI agents with Gemini on Google Cloud.

## Key Concepts
- Agent building with natural language
- Tool integration: Search, APIs, databases, extensions
- Enterprise search with grounding
- Conversational agents with Dialogflow CX
- Agent monitoring and evaluation

## Common Patterns
- Customer support agent with enterprise knowledge base
- Code assistant grounded in private repos
- Research agent with web search + data analysis
- Workflow automation agent with API integration
