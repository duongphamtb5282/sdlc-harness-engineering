# NestJS Auth & Security

Authentication and authorization in NestJS.

## Key Concepts
- @nestjs/passport + passport strategies (JWT, OAuth, local)
- JWT access + refresh token pattern
- @nestjs/throttler for rate limiting
- Helmet for security headers
- CORS configuration
- CSRF protection
- Role-based access control (RBAC) with custom guards

## Common Patterns
- JWT authentication with PassportStrategy
- Refresh token rotation for security
- Role/permission guards with custom decorator
- API key authentication for machine-to-machine
