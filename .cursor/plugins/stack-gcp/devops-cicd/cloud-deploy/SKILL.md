# Cloud Deploy

Delivery pipeline service for Google Cloud.

## Key Concepts
- Delivery pipelines with targets and stages
- Skaffold-based deployment for Cloud Run, GKE, GCE
- Automated rollout sequence with promotion
- Rollback and approval gates
- Deployment verification with Cloud Monitoring
- Canary and blue-green deployment strategies

## Common Patterns
- CI/CD with Cloud Build + Cloud Deploy
- Progressive delivery with canary analysis
- Multi-environment promotion (dev → staging → prod)
- GitOps with Cloud Deploy and Config Sync
