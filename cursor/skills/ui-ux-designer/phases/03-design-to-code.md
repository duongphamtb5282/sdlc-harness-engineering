# Phase 3: Design to Code

## Objectives
- Convert designs to reusable components
- Implement design tokens (colors, spacing, typography)
- Create responsive, accessible frontend code

## Activities
- Figma MCP: extract design tokens and component specs
- Implement components in React/Vue/Flutter
- Responsive implementation for mobile, tablet, desktop

## Outputs
- Component implementations
- Design token files (CSS variables, Tailwind config, style-dictionary)
- Responsive preview links

## MCP Requirements
- `figma` MCP server with FIGMA_ACCESS_TOKEN
