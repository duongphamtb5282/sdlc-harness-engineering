# Vertex AI Gemini

Gemini API on Google Cloud — multimodal LLM for text, code, images, audio, video.

## Key Concepts
- Gemini 1.5 Flash, Pro, Ultra models
- Multimodal prompting: text, image, audio, video, PDF
- Context caching for repeated prompts
- Grounding with Google Search, web, private data
- Safety settings and content filters

## Common Patterns
- Chat applications with streaming
- Multimodal document analysis
- Code generation and review
- Content summarization and extraction
- Agentic applications with function calling
