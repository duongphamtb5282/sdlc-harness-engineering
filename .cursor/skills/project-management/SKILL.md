# Project Management Skills

This skill provides access to project management tools through MCP integration.

## Available Skills

Refer to `.claude/plugins/project-management/skills/` for the full skill set:

- **jira/** — Jira issue tracking, story management, sprint planning
- **jira-automation/** — Automated Jira workflows and transitions
- **linear-automation/** — Linear issue tracking automation
- **qa-test-planner/** — Test planning and quality assurance workflows

## MCP Requirements

- `jira` MCP server with `JIRA_HOST`, `JIRA_USER`, `JIRA_API_TOKEN`
- `confluence` MCP server (optional, for documentation)
