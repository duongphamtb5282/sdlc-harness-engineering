# Phase 2: UI Design

## Objectives
- Create visual designs following design system
- Design responsive layouts for all breakpoints
- Ensure WCAG 2.1 AA accessibility compliance

## Activities
- Wireframing and prototyping
- Visual design (typography, color, spacing, icons)
- Accessibility review (contrast, focus, screen readers)

## Outputs
- `docs/design/wireframes/` — Wireframe screens
- `docs/design/visual-specs.md` — Visual specifications
- `docs/design/accessibility-report.md` — A11y compliance report
