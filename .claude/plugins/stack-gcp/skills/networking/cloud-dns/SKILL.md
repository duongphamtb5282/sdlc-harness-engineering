# Cloud DNS

DNS service on Google Cloud — programmable, scalable, reliable.

## Key Concepts
- Public zones for internet-facing DNS
- Private zones for internal DNS resolution
- Managed zones with DNSSEC support
- Routing policies: geo, weighted, failover
- Cloud DNS logging and monitoring

## Common Patterns
- Multi-region failover with DNS routing policies
- Split-horizon DNS (public + private)
- DNS peering across VPCs
- External DNS migration to Cloud DNS
