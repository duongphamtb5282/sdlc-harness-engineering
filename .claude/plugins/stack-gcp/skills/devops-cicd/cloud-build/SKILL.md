# Cloud Build

CI/CD platform for Google Cloud — build, test, deploy.

## Key Concepts
- Build config with cloudbuild.yaml
- Triggers: push, PR, scheduled, manual, webhook
- Build steps with Docker, Kaniko, custom runners
- Artifact Registry integration
- Cloud Build private pools
- Approvals for production deployments

## Common Patterns
- CI/CD for Cloud Run with Cloud Deploy
- Multi-environment promotion pipeline
- Container build and push to Artifact Registry
- Infrastructure-as-Code with Terraform via Cloud Build
