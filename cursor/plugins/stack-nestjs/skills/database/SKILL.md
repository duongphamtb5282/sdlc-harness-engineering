# NestJS Database

Database integration in NestJS.

## Key Concepts
- @nestjs/typeorm: TypeORM integration with repositories
- @nestjs/prisma: Prisma ORM integration
- @nestjs/mongoose: MongoDB with Mongoose
- @nestjs/sequelize: Sequelize ORM integration
- Migrations and seeds
- Transactions with @Transactional or query runner
- Database testing with test containers

## Common Patterns
- Prisma as modern TypeScript ORM (preferred)
- Repository pattern with custom providers
- Soft deletes with custom decorators
- Audit logging with entity listeners
