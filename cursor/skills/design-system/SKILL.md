# Design System Skills

This skill provides access to UI/UX design capabilities through Figma MCP integration.

## Available Skills

Refer to `.claude/plugins/design-system/skills/` for the full skill set:

- **figma/** — Figma design file access, component inspection, export
- **figma-implement-design/** — Convert Figma designs to code
- **frontend-design/** — Frontend design patterns and best practices
- **ui-design-system/** — Design token management and component library creation

## MCP Requirements

- `figma` MCP server with `FIGMA_ACCESS_TOKEN` environment variable
